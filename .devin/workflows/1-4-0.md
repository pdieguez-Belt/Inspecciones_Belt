# v1.4.0 - Detección Vehicular en Tiempo Real

## Características
- COCO-SSD para detección de tipo de vehículo (auto/camioneta/moto)
- Gemini AI para validación de ángulo/lado en tiempo real (pre-captura)
- Silueta verde solo cuando ambas capas confirman encuadre correcto

## Requisitos
- Variable de entorno `GEMINI_KEY` con API key de Google AI Studio
- TensorFlow.js y COCO-SSD se cargan por CDN

## Build
```bash
npx vite build --base /1-4-0/ --outDir dist-beta
# Copiar a dist/1-4-0/
cp -r dist-beta/* dist/1-4-0/
# Copiar assets estáticos
cp dist/logo-belt.png dist/manifest.json dist/sw.js dist/1-4-0/
cp -r dist/img dist/1-4-0/img
cp -r dist/icons dist/1-4-0/icons
```
